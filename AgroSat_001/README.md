# 🛰️ AgroSat — Interface Frontend de Agricultura de Precisão

Aplicação **100% Frontend** (React + TypeScript + Vite + Tailwind CSS) com foco em agricultura de precisão para Angola e África Subsaariana.

## Características
- **Exclusivamente Frontend:** Sem backend, sem servidor, sem base de dados, sem autenticação e sem chamadas a APIs externas.
- **Navegação Completa no Cliente:** Acesso direto a todas as páginas (`Início`, `Dashboard`, `Propriedades`, `Módulo NDVI`, `Histórico`, `Clima`, `AgroSat AI`, `Educação`, `Quizzes`, `Alertas` e `Perfil`).
- **Interações Simuladas Localmente:**
  - Gestão local de propriedades e alertas.
  - Visualização interativa de mapas, gráficos de série temporal NDVI e relatórios.
  - Previsão meteorológica simulada para as 21 províncias de Angola e capitais africanas.
  - Assistente interativo com respostas agronómicas simuladas localmente.
  - Upload e pré-visualização local de foto de perfil.
  - Cursos e quizzes interativos com progresso guardado no navegador.

## Execução Local
```bash
npm install
npm run dev
```

## Build de Produção
```bash
npm run build
npm run preview
```
